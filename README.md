# Overview

**Realistic 3D Watch** is an interactive computer graphics project developed using **C++**, **OpenGL**, **GLU**, and **freeglut**.

The application renders a detailed 3D analog wristwatch and displays the **current system time in real time**. The watch model includes multiple visual components such as a metallic case, bezel, dial with markers, and animated hands.

The project was designed to demonstrate practical computer graphics concepts including:

- 🧊 3D object modeling
- 🔄 Geometric transformations
- 💡 OpenGL lighting
- ✨ Material properties and specular highlights
- 🔍 Depth testing
- 🪞 Transparency and crystal effects
- ⏱️ Real-time animation
- 🖥️ Perspective projection
- 🎮 Interactive rotation and zoom controls

# ✨ Features

## ⌚ Real-Time Analog Watch

The watch reads the computer's local system time and continuously updates its hands.

### Time Components

- 🕐 Hour hand
- 🕑 Minute hand
- 🔴 Second hand
- 📅 Date display

The hour and minute hands move smoothly based on the current time.

---

## 🧱 Detailed 3D Watch Model

The project models several individual components to create a more realistic watch.

### Watch Components

- Stainless-steel style watch case
- Metallic bezel
- Dark watch dial
- Raised hour markers
- Minute markers
- Hour hand
- Minute hand
- Smooth second hand
- Center jewel
- Side crown
- Bezel details
- Date window
- Sapphire crystal effect
- Watch strap
- Strap details

---

## 💡 Lighting and Materials

Lighting is used to improve the depth and realism of the 3D model.

The project demonstrates:

- Ambient lighting
- Diffuse lighting
- Specular highlights
- Material shininess
- Multiple lighting effects
- Metallic surface appearance

Different material properties help distinguish between surfaces such as:

| Material | Visual Purpose |
|---|---|
| 🔩 Metal | Watch case, bezel, markers |
| 🌑 Dark material | Watch dial |
| ✨ Reflective material | Crystal and polished surfaces |
| 🟤 Leather-style material | Watch strap |
| 🔴 Accent material | Second hand |

---

## 🎮 Interactive Controls

You can interact with the watch while the application is running.

| Key / Input | Action |
|---|---|
| `↑` | Rotate watch upward |
| `↓` | Rotate watch downward |
| `←` | Rotate watch left |
| `→` | Rotate watch right |
| `W` | Rotate vertically |
| `S` | Rotate vertically |
| `A` | Rotate horizontally |
| `D` | Rotate horizontally |
| `+` / `=` | Zoom in |
| `-` / `_` | Zoom out |
| Left Mouse Button | Zoom in |
| Right Mouse Button | Zoom out |
| `Q` | Exit application |
| `ESC` | Exit application |
